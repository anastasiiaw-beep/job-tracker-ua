# 💼 UA Job Tracker & Analytics Dashboard

Автоматизированный инструмент для сбора, анализа и трекинга вакансий в IT-сфере с украинских платформ (**Work.ua** и **Djinni.co**).

## 🚀 Основной функционал

- Парсинг вакансий: Автоматический сбор вакансий по ключевым словам (*Python, Data Analyst, SQL*).
- База данных: Сохранение уникальных записей в SQLite с защитой от дубликатов.
- Интерактивный дашборд: Веб-интерфейс на Streamlit с фильтрацией по источникам и поиску.
- Трекинг откликов: Возможность сохранять статусы откликов (Собеседование, Оффер, Отказ и т.д.) и экспортировать историю в CSV.
- Telegram Уведомления: Бот автоматически отправляет свежие вакансии с уровнем ЗП от $500.
- Аналитика: Наглядные графики распределения зарплат и количества вакансий по платформам.

## 🛠 Технологии

- Python 3.10+
- Streamlit (веб-интерфейс и дашборд)
- BeautifulSoup4 / Requests (парсинг веб-страниц)
- SQLite3 / Pandas (хранение и обработка данных)
- Telegram Bot API (уведомления)
